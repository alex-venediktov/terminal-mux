# Настройки проекта для «Волны»

> Файл **коммитится** — это общая для команды часть настроек: команды и конвенции, без секретов
> и без машинных путей. Всё приватное берётся из `.env` и здесь упоминается только именем
> переменной. Проверить — `/volna:doctor`.

## Профиль

- репозитории: один
- трекер: нет
- приём задач: текст
- доставка: commit+push
- закрытие: журнал
- эталон: нет

Имена ключей и значений менять нельзя: по ним профиль читают этапы и hooks (`readProfile`).

Что это значит для этапов:

- работа идёт в репозитории с `.volna`, `repos[]` журнала пуст;
- все задачи локальные (`mode: local`): статусы никуда не пишутся, задача-фикс и PR не создаются;
- `/volna:task` принимает текст или файл; число читается как локальный id;
- `deliver` = коммит и push, PR не создаётся;
- `close` идёт ветвью Г: часы и итог в журнал;
- сверки с эталонной реализацией нет, правила порта не применяются.

## База знаний

MCP-сервер поиска по коду: имя — `KB_MCP_NAME`. Сервер не настроен → искать `Grep`/`Glob`
и отмечать это в журнале.

## Команды

| Зачем | Команда |
|---|---|
| установка зависимостей | `npm install` |
| запуск для разработки | `npm run tauri dev` |
| сборка exe и установщиков | `npm run tauri build` (итог в `src-tauri/target/release/` и `.../bundle/`) |
| проверка типов фронтенда | `npx tsc --noEmit` |
| юнит-тесты | `cargo test --manifest-path src-tauri/Cargo.toml` |

Строка «чего не запускать» — про прогоны с внешними последствиями: назвать команду, причину и
замену одной строкой. Пустая означает «ограничений нет».

## Конвенции

- ветка: `bugfix/<id>-<slug>` для bug, `feature/<id>-<slug>` для story/task; целевая ветка
  для отвода новых и слияния — `TARGET_BRANCH`;
- коммит: одна строка `<id> <что сделано>`; `git add -A` перед коммитом; **без** трейлеров
  (в том числе без `Co-Authored-By`);
- комментарии: одна строка «что делает (`<источник>`)», русский язык,
  ASCII-пунктуация (`->`, `-`, `"`), без номеров задач;
- тесты (Rust): имя-утверждение в snake_case (`cmd_in_conpty_echoes_typed_command_output`), обязательный `///`
  doc-комментарий одной фразой о проверяемом поведении; тест рядом с кодом в `mod tests`.

## Локальное (не коммитить)

Машинно-зависимое — в `.env`; всё, что нужно вынести из этого файла персонально, —
в `.volna/project.local.md` (уже в `.gitignore`).
