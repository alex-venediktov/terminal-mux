# В Windows claude и pi вставляют картинку из буфера по Alt+V и читают буфер сами

**тип:** особый случай · **предмет:** вставка картинки · **этапы:** implement

**вывод:** Ctrl+V в Windows забирает терминал под вставку текста, поэтому сочетание вставки картинки
у обоих приложений - Alt+V (`ESC v`): у pi это `app.clipboard.pasteImage` в `docs/keybindings.md`,
у Claude Code - `De=Be?"alt+v":"ctrl+v"` в исполняемом файле, где `Be` - Windows или WSL. Хост не
передаёт картинку данными: увидев в буфере картинку без текста, он шлёт приложению это сочетание.

**источник:**
- `src-tauri/src/config.rs:21` — `"pasteImage": "\u{1b}v"`
