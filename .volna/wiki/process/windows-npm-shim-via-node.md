# npm-обёртку .cmd в псевдоконсоли запускают через node, а не через cmd /c

**тип:** побочный эффект · **предмет:** запуск npm-команд · **этапы:** implement

**вывод:** глобальные npm-команды в Windows - обёртки `.cmd`. Запущенная через `cmd /c`, обёртка
перехватывает Ctrl+C вопросом «Terminate batch job (Y/N)?», и приложение (pi) не получает сочетание
как своё. Путь к скрипту пакета читается из обёртки (`"%dp0%\...\cli.js"`), и запускается `node`
с этим скриптом напрямую.
