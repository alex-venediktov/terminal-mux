# Процесс с повышенными правами нельзя подключить к ConPTY обычного процесса

**тип:** ограничение · **предмет:** повышение прав · **этапы:** analyze, implement

**вывод:** граница UAC не пускает процесс администратора в псевдоконсоль процесса с обычными
правами. Варианты: отдельное окно через `ShellExecute` с глаголом `runas` (диалог UAC, как из

повышенными правами - ослабляет границу UAC. Отказ в диалоге даёт ошибку `ERROR_CANCELLED` (1223).
