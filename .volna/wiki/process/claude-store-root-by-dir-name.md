# Корень проекта в хранилище Claude Code задаёт имя каталога, а не поле cwd журнала

**тип:** ограничение · **предмет:** хранилище сессий claude · **этапы:** analyze, implement

**вывод:** `cwd` в записях `~/.claude/projects/<имя>/*.jsonl` - текущий каталог оболочки: он
меняется при `cd` и устаревает, если папку проекта переименовали. Корень кодируется именем
каталога хранилища (у pi - `~/.pi/agent/sessions/--<имя>--`), но неоднозначно: любой символ,
кроме букв и цифр ASCII, становится `-`. Путь восстанавливается сверкой имени с реальными
каталогами диска; `cwd` сессии годится, только если его кодирование совпадает с именем.
