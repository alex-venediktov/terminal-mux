# Сборка Tauri не перезаписывает запущенный exe, но работающий файл можно переименовать

**тип:** ограничение · **предмет:** сборка Tauri · **этапы:** visual, deliver

**вывод:** `npm run tauri build` кладёт exe в `src-tauri/target/release/terminal-mux.exe`, и если
приложение запущено из этого же файла, запись падает на занятом файле. Windows разрешает
переименовать работающий exe (`terminal-mux.prev.exe`): процесс продолжает работать, сборка пишет
новый файл на освободившееся место. Старый файл удаляется после закрытия процесса. Дев-сборка
(`npm run tauri dev`) путь не занимает, но делит с запущенным экземпляром
`~/.terminal-mux/config.json` и состояние окна.
