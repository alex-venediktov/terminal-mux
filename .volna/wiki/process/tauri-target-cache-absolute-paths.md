# После переноса каталога Tauri-проекта сборка требует cargo clean

**тип:** ограничение · **предмет:** сборка Tauri · **этапы:** implement, deliver

**вывод:** кеш `src-tauri/target` хранит абсолютные пути build-скриптов: после переноса или
переименования каталога проекта сборка падает на чтении файлов разрешений Tauri
(`permissions/.../autogenerated`). Лечит `cargo clean`. Запущенный exe не даёт пересобрать себя, но
Windows разрешает переименовать работающий файл - сборка пишет новый рядом, процесс не трогается.
