# Shift+Enter через ConPTY к приложению доходит, только если его закодировал хост

**тип:** ограничение · **предмет:** клавиши через ConPTY · **этапы:** implement

**вывод:** модификаторы Enter ConPTY передаёт только в win32-input-mode (`CSI ?9001h`), а xterm.js
этот режим не поддерживает: Shift+Enter приходит как обычный Enter. Хост перехватывает сочетание и
шлёт последовательность, которую ждёт приложение: Claude Code - `ESC CR`, pi - `CSI 13;2u`
(протокол клавиатуры kitty). Оба варианта проверены вживую.

**источник:**
- `src-tauri/src/config.rs:35` — `"shiftEnter": "\u{1b}[13;2u",`
