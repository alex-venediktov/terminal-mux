# Свёрнутость каталога в панели проектов привязана к последнему сегменту склеенной цепочки

**тип:** ограничение · **предмет:** дерево панели проектов · **этапы:** implement, advocate

**вывод:** каталог без проекта с единственным потомком склеивается с ним в одну строку, и узел
получает ключ потомка - полный путь последнего сегмента в нижнем регистре. Этот ключ хранится в
`collapsed` конфига. Когда в цепочке появляется второй проект, склейка распадается, ключ строки
меняется, и свёрнутость, сохранённая под прежним ключом, не применяется.
